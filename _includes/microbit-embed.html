{% comment %} Embeds a MakeCode micro:bit project's live simulator, given the code from its share link (include.id, e.g. "_gAg42F0RuVm4"). Mirrors scratch-embed.html. MakeCode's simulator has no fixed aspect ratio - it sizes its own `.simframe` element with a `padding-bottom` percentage computed at runtime, which grows taller for a project that attaches extra simulator parts (e.g. the external speaker some music blocks show) than for a bare board. 145% (include.ratio) is measured against a project with an attached part; for a bare-board project, pass a smaller include.ratio (find the exact figure by opening the project's own https://makecode.microbit.org/---run?id= page and inspecting its `.simframe` element's inline style) or accept the extra blank space below the board - better than the board being cut off, which is what an undersized ratio does. {% endcomment %}
